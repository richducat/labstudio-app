# System Anti-Friction / Anti-Dumb-Questions

Rule: if an action is an obvious reliability hardening step (drift protection, audits, guardrails, collision detection) and it is low-risk / reversible and internal-only, **do it by default**.

Do NOT ask Richard if he wants it.

Only ask when:
- external send / money / legal / cancellation / irreversible actions
- destructive actions
- high risk of breaking production

This exists because asking obvious questions increases stress and reduces trust.
